# Public reference implementations

These samples expose the decision logic behind three personally built architecture patterns without publishing client source code, customer data, credentials, proprietary schemas, or deployment configuration.

- `governed-agent-runtime`: policy, budget, approval and audit controls around tool execution.
- `permission-aware-rag`: ACL-first hybrid retrieval with confidence-based answer, clarify and refuse modes.
- `delivery-control-tower`: deterministic portfolio metrics, evidence lineage and exception-led operating narratives.

Each sample uses only the Python standard library and includes tests. The implementations are intentionally compact teaching references, not copies of production repositories.
