# Public presentation library

This folder contains four curated public decks plus the authorized 16-file archive of all 2,256 unique source slides.

- `governed-agentic-ai`: value intent, runtime policy, tool execution, evidence and adoption.
- `permission-aware-rag`: ACL-first retrieval, hybrid ranking, grounding and response policy.
- `delivery-control-tower`: semantic contracts, deterministic metrics, agent-assisted analysis and operating action.
- `master-portfolio`: a 28-slide synthesis of enterprise operating systems, banking architecture, governed AI, delivery evidence, productisation and adoption.
- `full-library`: the manifest for the complete deduplicated slide archive, preserved as 16 versioned PowerPoint assets in the [`slide-archive-2026-08-30`](https://github.com/singhaditya21/Resume/releases/tag/slide-archive-2026-08-30) GitHub release.

The three mini-deck folders contain the `.pptx` and six browser-ready slide previews. The master portfolio is provided as a single downloadable `.pptx`. These four curated decks are customer-neutral public reconstructions of recurring patterns from my delivery record. The separately labeled full library remains fully downloadable from its versioned release, is published with owner authorization, and may retain historical customer, project and proprietary delivery context.
