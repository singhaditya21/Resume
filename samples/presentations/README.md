# Public presentation samples

Four editable public decks demonstrate how I structure enterprise architecture stories without exposing a customer identity or confidential implementation.

- `governed-agentic-ai`: value intent, runtime policy, tool execution, evidence and adoption.
- `permission-aware-rag`: ACL-first retrieval, hybrid ranking, grounding and response policy.
- `delivery-control-tower`: semantic contracts, deterministic metrics, agent-assisted analysis and operating action.
- `master-portfolio`: a 28-slide synthesis of enterprise operating systems, banking architecture, governed AI, delivery evidence, productisation and adoption.

The three mini-deck folders contain the `.pptx` and six browser-ready slide previews. The master portfolio is provided as a single downloadable `.pptx`. Source notes identify the public résumé/portfolio basis and explicitly state the confidentiality boundary. These are original public reconstructions of recurring patterns from my delivery record, not client deliverables or claims that one customer used the exact reference stack shown.
