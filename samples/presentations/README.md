# Public presentation samples

Three editable, six-slide mini-decks demonstrate how I structure an enterprise architecture story without exposing a customer identity or confidential implementation.

- `governed-agentic-ai`: value intent, runtime policy, tool execution, evidence and adoption.
- `permission-aware-rag`: ACL-first retrieval, hybrid ranking, grounding and response policy.
- `delivery-control-tower`: semantic contracts, deterministic metrics, agent-assisted analysis and operating action.

Each folder contains the `.pptx` and six browser-ready slide previews. Source notes in the decks identify the public résumé/portfolio basis and explicitly state the confidentiality boundary. These are original public reconstructions of recurring patterns from my delivery record, not client deliverables or claims that one customer used the exact reference stack shown.
