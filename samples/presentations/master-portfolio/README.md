# Master architecture portfolio

`Aditya_Singh_Master_Architecture_Portfolio.pptx` is a 28-slide, customer-neutral public portfolio deck. It consolidates recurring patterns across enterprise operating systems, banking architecture, governed AI, delivery evidence, productisation and adoption.

The deck is a public reconstruction for review. It contains no customer names, customer data, proprietary schemas, production configuration or confidential implementation detail. The full internal slide corpus remains excluded from Git and GitHub Pages.
