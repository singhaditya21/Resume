# Delivery Command Center

- **Evidence status:** Source-backed prototype
- **Category:** Data & decision intelligence
- **Source package:** `Delivery Command Center.zip`

A leadership portfolio cockpit combining delivery, revenue, case, risk and action evidence with grounded AI signals and rule-based fallback.

The technical claims below are grounded in the supplied source archive.

## AI or automation role

Compact aggregate facts are sent to a model for strict-JSON alerts, nudges and insights; normalization and deterministic rules keep the factual baseline authoritative.

## Technical stack

Python · FastAPI · SQLAlchemy · PostgreSQL · React · TypeScript · OpenAI API · Docker

## Skills demonstrated

- Portfolio analytics
- Data lineage
- Grounded insight generation
- Fallback rules
- Executive visualization
- API design

## Primary system flow

CRM and supplementary sources → SQL aggregation → Portfolio API → Factual digest → Model or rules → Dashboard signals
