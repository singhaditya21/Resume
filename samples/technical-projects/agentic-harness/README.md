The technical claims below are grounded in the supplied source archive.

## AI or automation role

Speech, speaker, embedding, retrieval, vision and hosted/local language models refine deterministic MEDDICC and BANT scoring into an evidence-backed deal analysis.

## Technical stack

Python · Streamlit · n8n · Chroma · SentenceTransformers · Parakeet · pyannote · OpenCV

## Skills demonstrated

- Conversation intelligence
- Multimodal processing
- RAG
- Deal methodology scoring
- Provider abstraction
- Workflow orchestration

## Primary system flow

Video audio and documents → ASR diarization and OCR → Transcript chunking → Vector retrieval → Deal scoring and LLM refinement → Dashboard and workflow actions
