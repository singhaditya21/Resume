# DBProd Governed Analytics Copilot

- **Evidence status:** Code-derived architecture
- **Category:** Agentic AI & automation
- **Source package:** `DBProd.zip`

A governed natural-language analytics copilot built around typed semantic plans, deterministic SQL compilation, bounded model advice and evidence-gated learning.

The technical claims below are grounded in the supplied source archive.

## AI or automation role

Retrieval and a bounded advisor may select from safe semantic candidates, but every proposal returns through typed compilation, ownership policy and read-only SQL controls.

## Technical stack

Python · PostgreSQL · Redash · scikit-learn · SentenceTransformers · SSE · Docker · Caddy

## Skills demonstrated

- Secure text-to-SQL
- Semantic layers
- Model authority boundaries
- Learning governance
- Schema drift
- Release evidence

## Primary system flow

Natural-language question → Semantic catalog retrieval → Bounded model advisor → Typed SQL compiler → Security gates and Redash → Masked answer or learning job
